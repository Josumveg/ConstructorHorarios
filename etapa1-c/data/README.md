# data/

Carpeta para los archivos de entrada y salida del programa:

- `catalogo.txt` (o el formato que el equipo acuerde): catálogo de cursos recolectado de la Guía de Horarios del TEC (ver sección 4 de [../distribucion-tareas-etapa1-cemestre.md](../distribucion-tareas-etapa1-cemestre.md)).
- `historial.txt`: historial de cursos aprobados de un estudiante de prueba.
- `catalogo_salida.json` (o `.csv`): archivo exportado por el programa, contrato con la etapa de Racket.
